# Additional Instructions
This license is intended for MATLAB R2025b.

If MATLAB opens and immediately closes when you launch the program, go to:

C:\Program Files\MATLAB\R2025b

Create a folder named:

licenses

Then place your license.lic file (downloaded from this page) inside the licenses folder and launch MATLAB again.
