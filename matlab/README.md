# Additional Instructions
This license is intended for MATLAB R2025b.

If MATLAB opens and then closes immediately, make sure that you have a valid and authorized license. If your MATLAB installation requires a local license file, go to:

C:\Program Files\MATLAB\R2025b

Create a folder named:

licenses

Then place your authorized license.lic file inside that folder and launch MATLAB again.
